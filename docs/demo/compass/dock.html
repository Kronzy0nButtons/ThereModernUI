Appearance
Accent colour for the whole UI, and what the dock shows besides its buttons.
Controls
In Action Mode (or while aiming a gun): W A S D move, Space jumps, R reloads and other letters don’t type. Press Enter to chat (Action Chat) and Enter again to send. F1 to F12 use your Quick Bar slots at any time.
UI Behaviour
How the dock behaves while you play: panels that close themselves after you use them, and the speedometer that appears when you drive.
GIFs
Share GIFs from KLIPY in chat. Other ThereModernUI users see them pop up above their dock; everyone else sees a short [TMUI] [GIF] code.
Dock buttons
Choose what shows on the dock. It resizes itself to fit; hidden buttons stay in the Library.
Sync & data
Live sync
Inventory, clothing and item actions sync at startup and refresh automatically, so things work instantly and background changes (purchases, trades, gifts) appear on their own.
↻ Sync now
🗑 Clear image cache
Requests to the game
The dock asks the game for item details in a queue, a few at a time, so a burst of them can't stall it. More at once loads faster; fewer is smoother. When the queue backs up, the bar above the dock says so.
Folders backup
Your folders and the items in them are saved on this machine only, per avatar. Export a backup file before reinstalling There, then import it afterwards to restore them for this avatar.
📥 Export folders
📤 Import folders
Music search
Song search uses a free, keyless Piped instance. Public instances come and go, so if search stops working, pick another below or paste your own.

Updates
The dock asks GitHub for new releases every 15 minutes and puts a strip on the dock when one is out. Show update puts that strip up for the release that is out now, so the whole process can be tried from it: the setup downloads, offers to close There, installs and starts There again.
